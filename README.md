# TempleOS

TempleOS V5.03 source tree. See [ReadMe.TXT](ReadMe.TXT) for the original
notes.

**Run it on Windows, macOS, or Linux without setting up a VM:** see
[Standalone/README.md](Standalone/README.md). One download boots TempleOS,
built from this tree. The Windows and macOS apps were originally published
by [noisyloop](https://github.com/noisyloop/TempleOS).

**On 64-bit ARM Linux, TempleOS can also run as native ARM code.**
`TempleOS-Linux-arm64-native` is a single executable. HolyC from this tree
is compiled to aarch64 machine code and runs in a Linux process. The window
is the stock 640×480 16-color desktop. There is no PC emulator in that
build. Details, gaps, and the later-phase roadmap are in
[Standalone/README.md](Standalone/README.md#native-aarch64) and
[Native/README.md](Native/README.md).
